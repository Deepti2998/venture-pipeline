## Design Decisions

- One source deep: YC has enough structured fields to produce traceable candidate records. This avoids the anti-pattern of many weak sources.
- Deterministic first: reviewers can run the pipeline without API keys. Optional LLM enrichment exists, but the score and recommendation are reproducible without it.
- Traceable claims: every memo includes evidence links and source snippets. When founder backgrounds are missing, the memo says so instead of inventing detail.
- Small system: no database, queue, vector store, or frontend. The pipeline writes JSON and Markdown artifacts.
